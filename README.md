SQL Mini Project 2
Обзор проекта
Этот проект демонстрирует практические навыки SQL с использованием MySQL. Работа включала создание баз данных, создание таблиц, загрузку данных, анализ данных, агрегирование, фильтрацию, подзапросы и объединения.

Выполненные задачи
Часть 1: Анализ пользовательской активности
Создал базу данных MySQL и проанализировал данные о активности пользователей из таблицы. Выполненные задачи:users

Рассчитал количество уникальных пользователей для выбранного диапазона дат.
Определили пользователя с наибольшим количеством просмотров рекламы.
Нашёл день с самым высоким средним количеством просмотров рекламы на одного пользователя, учитывая только дни с более чем 500 уникальными пользователями.
Рассчитывал продолжительность жизни пользователя на платформе на основе активных дней.
Определил пользователя с наибольшим средним ежедневным просмотром рекламы среди активных пользователей не менее 5 дней.
Часть 2: Анализ продаж продукта и сотрудников
Создан отдельный MySQL базу данных с двумя таблицами:

T_TAB1 - данные о продажах продукции
T_TAB2 - данные сотрудников
Обработанные данные включали:

10 рекордов по продажам продукции
5 сотрудников
4 категории продуктов
4 активных продавца
1 сотрудник без продаж
Выполненные задачи:

Нашли уникальные категории товаров.
Рассчитано общее количество и сумма продаж мобильных телефонов.
Отобранные сотрудники с зарплатой выше 100 000.
Рассчитаны минимальный и максимальный возраст и зарплата.
Рассчитано среднее количество проданных для клавиатур и принтеров.
Рассчитал общую сумму продаж по продавцам.
Объединил таблицы продаж и сотрудников для анализа данных продавцов.
Выявлены сотрудники без продаж.
Отфильтровали сотрудников по возрасту.
Проверил поведение JOIN для сотрудников без совпадения записей о продажах.
